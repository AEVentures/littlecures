# Outreach Kit

Ready-to-use copy for every channel where LittleCures should show up.

| File | Use it for |
|------|-----------|
| [`X_THREADS.md`](./X_THREADS.md) | Threads to post on X / Twitter |
| [`LINKEDIN_POSTS.md`](./LINKEDIN_POSTS.md) | Long-form LinkedIn posts |
| [`HN_SHOW.md`](./HN_SHOW.md) | The Hacker News Show HN draft |
| [`COLD_EMAILS.md`](./COLD_EMAILS.md) | Cold emails for clinicians, funders, peers, journalists |
| [`PRESS_KIT.md`](./PRESS_KIT.md) | One-page facts + quotes for journalists and partners |

Anyone can contribute new templates. Open a PR and add another file.
