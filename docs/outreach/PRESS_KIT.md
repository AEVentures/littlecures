# LittleCures Press Kit

Everything a journalist, editor, or partner needs in one place.

## The one-liner

LittleCures is an open-source, patient-first project building the shared infrastructure needed to accelerate cures for children with cancer.

## The 30-second pitch

Pediatric cancer is scientifically neglected: drugs are developed for adults, tumor data is siloed across hospitals, and access is deeply unequal — with survival for the same disease often four times higher in high-income countries than in low-income ones. LittleCures is a non-profit, MIT-licensed effort building the open tools this field is missing: open trial matching, an open target and IP registry, federated learning across hospitals, and access advocacy. Everything is public, everything is free to use, and the roadmap lives on GitHub.

## Common questions

**Is this a company or a charity?**
Neither yet. It is an open-source project under the AEVentures venture group. Formal 501(c)(3) status is on the roadmap once we have a first funder committed.

**Where does the code and data live?**
All code lives on GitHub under `AEVentures/littlecures`. All data will be public and openly licensed unless it involves patient records — those stay in institutional systems, and we build federated tools that leave them there.

**How is this different from St. Jude or the Children's Cancer Foundation?**
We are complementary, not competitive. Those are extraordinary institutions doing clinical care and grant-funded research. LittleCures builds the shared open-source tooling that no single institution owns — the trial-matching engine, the target registry, the federated learning software — so that every hospital and every research group can benefit.

**Who is on the team right now?**
The founder, plus contributors who arrive through GitHub. If you want to join, see https://littlecures.org/#tracks.
