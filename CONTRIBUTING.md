# Contributing to LittleCures

Thank you for considering contributing. This work matters.

## Ways to contribute

- **Code:** build features, fix bugs, improve tooling.
- **Design and writing:** make the site, docs, and data legible to families and policymakers.
- **Clinical and scientific input:** review accuracy, advise on models, and connect real-world needs.
- **Advocacy and outreach:** share the project, help recruit contributors, and keep the work patient-first.

## Getting started

See [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md) for install, build, test, and project structure.

For collaboration norms, communication channels, and decision making, see [docs/COLLABORATION.md](docs/COLLABORATION.md).

For the long-term roadmap and architecture, see [docs/ROADMAP.md](docs/ROADMAP.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Guidelines

- Keep changes focused. One concern per pull request.
- Write clear commit messages.
- Add or update tests when adding logic.
- Keep components small and single-purpose.
- Use named exports.
- Follow the existing code style.

## Reporting issues

Use GitHub Issues. Include:

- A clear title
- Steps to reproduce, if it is a bug
- Expected and actual behavior
- Your environment (OS, browser, Node version)

## Need help?

Open a GitHub Discussion or comment on an issue. We will respond as quickly as we can.
